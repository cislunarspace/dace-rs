# dace-rs

Pure Rust implementation of DACE, the Differential Algebra Computational Toolbox.

`dace-rs` computes with truncated multivariate Taylor polynomials ("differential algebra"): high-order expansions of arbitrary multivariate functions, elementary-function composition by series, and exact algebraic manipulation of the resulting polynomial maps.
