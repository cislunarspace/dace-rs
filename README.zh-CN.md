# dace-rs

DACE（Differential Algebra Computational Toolbox，微分代数计算工具箱）的纯 Rust 实现。

`dace-rs` 使用截断的多变量 Taylor 多项式（“微分代数”）进行计算：任意多变量函数的高阶展开、通过级数实现的初等函数复合，以及对所得多项式映射的精确代数操作。
